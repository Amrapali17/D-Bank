# D-Bank Backend

This is the backend code for **D-Bank**, a secure decentralized banking system built with Node.js and MongoDB.

## 🔧 Features

- User Registration & Login (JWT Auth)
- Password Hashing (bcrypt)
- Email support (SMTP)
- Protected Routes (Middleware)
- MongoDB Atlas Integration

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB (Mongoose)
- dotenv
- bcrypt
- jsonwebtoken
- nodemailer
